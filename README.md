# Medium articles

Code, data and figures for my articles on Medium. Each article has its own folder with a notebook that reproduces every experiment and chart.

## Ensemble methods series

- Part 1: [Bagging and Random Forests](https://medium.com/@319257836/ensemble-methods-part-1-bagging-and-random-forests-d44cb6bd019c), with code in [ensemble-methods/part-1-bagging](ensemble-methods/part-1-bagging)
- Part 2: Boosting (coming soon)
- Part 3: Stacking (coming soon)

## Setup

```bash
git clone https://github.com/AlegreVentura/medium-articles.git
cd medium-articles
pip install -r requirements.txt
```

The charts use Open Sans, which is included in `fonts/` under the SIL Open Font License.
